## 1. Authentication & Session Governance Module

### Purpose
Provides a single, intelligent authentication entry point supporting multi-format identifiers with automatic password hashing upgrades and role-based portal dispatch.

### Responsibilities
- Resolve logins via: Email, Username (`admin`/`superadmin`/`branchadmin`), Branch Code (`BR001`), Staff Code (`STF001`), or Agent Member Code (`AG000042`).
- Verify credentials using Argon2id with automatic fallback and transparent rehashing from legacy Bcrypt (`Hash::needsRehash()`).
- Direct authenticated users to their authorized portal based on role hierarchy.
- Enforce brute-force throttling (`throttle:10,1`).

### Important Files
- Controller: `app/Http/Controllers/SuperAdmin/AuthController.php`
- Middleware: `app/Http/Middleware/AdminMiddleware.php`, `SuperAdminMiddleware.php`, `BranchAdminMiddleware.php`, `AgentMiddleware.php`
- Model: `app/Models/User.php`
- Views: `resources/views/superadmin/auth/login.blade.php`

### Inputs & Outputs
- **Input**: Login identifier (`login` or `email`) and `password`.
- **Output**: Authenticated session cookie or error flash message, followed by redirect to role dashboard.

### Permissions & Security
- Public / Guest only for login submission.
- Rate-limited via Laravel's built-in throttle middleware (`10` attempts per minute).

### Related Database Entities & Tests
- Entities: `users`, `roles`, `role_user`, `branches`, `staff`, `agents`.
- Tests: `tests/Feature/BranchAuthAndCreationTest.php`, `tests/Feature/BranchAdminAccessTest.php`.

## 2. Organization & Branch Hierarchy Module

### Purpose
Enables central society executives to provision, configure, and monitor regional physical branches and regional administrators.

### Responsibilities
- Create, update, and manage physical society branches.
- Assign unique branch codes (`BR001`, `BR002`), operational addresses, contact details, and initial status.
- Provision dedicated Branch Administrator user accounts tied to specific branches.
- Isolate operational data (staff, customers, deposits) by branch jurisdiction.

### Important Files
- Controllers: `app/Http/Controllers/SuperAdmin/BranchController.php`, `SuperAdmin\BranchAdminController.php`
- Models: `app/Models/Branch.php`, `User.php`
- Views: `resources/views/superadmin/branches/`

### Permissions & Scoping
- Restricted strictly to Super Administrators (`superadmin` middleware).
- Branch Admins are locked to their own branch via `AdminMiddleware::getRestrictedBranchId()`.

### Related Entities & Tests
- Entities: `branches`, `users`, `staff`, `deposits`, `audit_logs`.
- Tests: `tests/Feature/BranchAuthAndCreationTest.php`, `tests/Feature/BranchAdminAccessTest.php`.

## 3. Agent Hierarchy & Free Placement Module

### Purpose
Manages field agent onboarding, downline network structures, member codes, and flexible geographic placement.

### Responsibilities
- Onboard new field agents with autogenerated sequential Member Codes (`AG000001` via `NumberingService`).
- Generate secure random initial credentials via `PasswordGeneratorService` and dispatch welcome emails (`AccountWelcomeMail`).
- Support **Free-Floating Placement**: Agents can have a `null` `branch_id`, permitting cross-branch business mobilization.
- Maintain recursive downline tree relationships (`parent_agent_id`).
- Profile photo cropping and public storage pipeline (`ProfileImageService`).

### Important Files
- Controllers: `app/Http/Controllers/Admin/AgentController.php`, `Agent\DownlineAgentController.php`
- Services: `app/Services/NumberingService.php`, `PasswordGeneratorService.php`, `ProfileImageService.php`
- Models: `app/Models/Agent.php`, `CareerLevel.php`, `Branch.php`
- Mail: `app/Mail/AccountWelcomeMail.php`
- Views: `resources/views/admin/agents/`, `resources/views/agent/downline/`

### Permissions & Tests
- Super Admin & Branch Admin: Create, edit, verify, accept, or reject agents.
- Agent: View personal downline and enroll downline agents (`/agent/agents`).
- Tests: `tests/Feature/AgentModuleTest.php`, `tests/Feature/AgentDownlineManagementTest.php`, `tests/Feature/AgentFreePlacementTest.php`, `tests/Feature/AgentProfileImageCropTest.php`.

## 4. Staff Administration & Permission Allocation Module

### Purpose
Enables granular, least-privilege administration for operational employees and counter clerks.

### Responsibilities
- Manage branch staff profiles and employee IDs (`STF001`).
- Define organizational staff positions with sorting order (`positions` table).
- Provide Super Admins with an interactive **Permission Matrix** (`/superadmin/permissions`) to toggle discrete capabilities (e.g. `view-deposits`, `create-deposits`, `approve-commissions`, `manage-settings`) per staff member.
- Staff accounts never receive agent ranks and never appear in commission trees.

### Important Files
- Controllers: `app/Http/Controllers/Admin/StaffController.php`, `SuperAdmin\StaffPositionController.php`, `SuperAdmin\PermissionController.php`
- Models: `app/Models/Staff.php`, `StaffPosition.php`, `Permission.php`, `Role.php`
- Views: `resources/views/admin/staff/`, `resources/views/superadmin/permissions/`

### Permissions & Tests
- Super Admin: Full permission allocation and position management.
- Branch Admin: Manage branch staff profiles.
- Tests: `tests/Feature/StaffModuleTest.php`, `tests/Feature/StaffAndAgentAdministrationTest.php`, `tests/Feature/SuperAdminPermissionAndStaffAllocationTest.php`.

## 5. Lead CRM Pipeline Module

### Purpose
Provides field agents with a lightweight, mobile-responsive CRM tool to capture prospects, log follow-ups, and convert leads into deposit accounts with zero data re-entry.

### Responsibilities
- Field lead capture: Name, mobile, address, interested scheme, expected investment amount, follow-up dates, and notes.
- Status progression: `NEW` &rarr; `CONTACTED` &rarr; `INTERESTED` &rarr; `CONVERTED` (or `NOT INTERESTED`).
- Quick-status inline AJAX updates (`/agent/leads/{lead}/quick-status`).
- **1-Click Conversion**: Automatically pre-fills the deposit application form, creating the customer record and marking the lead `CONVERTED`.

### Important Files
- Controllers: `app/Http/Controllers/Agent/LeadController.php`, `Admin\LeadController.php`
- Model: `app/Models/Lead.php`
- Views: `resources/views/agent/leads/`, `resources/views/admin/leads/`

### Permissions & Tests
- Agents: Full CRUD over their own assigned leads.
- Admins: Read-only supervision across branch or global leads.
- Tests: `tests/Feature/AgentLeadManagementTest.php`, `tests/Feature/DepositCreateLeadAgentTest.php`, `tests/Feature/BranchAdminLeadAndCustomerTest.php`.

## 6. Customer & KYC Management Module

### Purpose
Maintains customer profiles, KYC compliance documents, and nominee declarations while preserving strict provenance via the deposit pipeline.

### Responsibilities
- Store customer demographics, contact information, identity proofs, address proofs, and nominee details.
- Link customers to their assigned booking agent and branch.
- **Architectural Policy**: Direct customer creation (`/admin/customers/create`) intentionally returns `404`. All customers must originate from either a Lead conversion or a Deposit creation workflow.

### Important Files
- Controller: `app/Http/Controllers/Admin/CustomerController.php`
- Models: `app/Models/Customer.php`, `CustomerKyc.php`
- Views: `resources/views/admin/customers/`

### Permissions & Tests
- Super Admin & Branch Admin: View and edit existing customer profiles.
- Agents: Prohibited from direct customer database access (manage through Leads).
- Tests: `tests/Feature/CustomerAndKycManagementTest.php`, `tests/Feature/CustomerLoginKycAndAddOptionRemovalTest.php`.

## 7. Deposit Scheme & Multi-Year Interest Rate Module

### Purpose
Defines society deposit products, calculation modes (FD, RD, DD, MRP), and tenure-tiered multi-year interest rate schedules.

### Responsibilities
- Create master deposit schemes with customizable parameters: minimum/maximum deposit amounts, tenure units (Days, Months, Years), lock-in periods, premature penalty percentages, and senior citizen bonus rates (+0.50%).
- Configure tenure-based multi-year interest rate tiers via `DepositSchemeInterestRate` (e.g. 1 Year: 10.0%, 2 Years: 10.5%, 3 Years: 11.0% up to 6 Years: 12.5%).
- Real-time preview of autogenerated scheme codes (`previewCode`) and tenure interest rate calculations.

### Important Files
- Controllers: `app/Http/Controllers/Admin/DepositSchemeController.php`, `SuperAdmin\DepositInterestRateController.php`
- Models: `app/Models/DepositScheme.php`, `DepositSchemeInterestRate.php`, `SchemeType.php`
- Views: `resources/views/admin/deposit-schemes/`, `resources/views/superadmin/interest-rates/`

### Permissions & Tests
- Restricted to Super Administrators.
- Tests: `tests/Feature/DepositSchemeConfigurationTest.php`, `tests/Feature/MultiYearDepositInterestRateTest.php`, `tests/Feature/DepositMultiYearInterestRateSystemTest.php`.

## 8. Deposit Account Lifecycle & Operations Module

### Purpose
Governs the creation, verification, activation, interest accrual, maturity settlement, and closure of customer deposit accounts.

### Responsibilities
- Capture deposit applications with customer details, scheme selection, tenure, payment mode (Cash, Bank Transfer, Cheque, UPI, DD), and nominee information.
- Calculate exact and rounded maturity amounts using server-side banking formulas.
- Execute 2-step verification (`verify`, `returnForCorrection`, `approve`, `activate`).
- Automatically generate multi-year commission payout schedules upon activation.
- Process maturity settlements and premature account closures.

### Important Files
- Controller: `app/Http/Controllers/Admin/DepositController.php`
- Model: `app/Models/Deposit.php`
- Service: `app/Services/NumberingService.php`
- Views: `resources/views/admin/deposits/`

### Permissions & Tests
- Creation: Super Admin, Branch Admin, and Staff with `create-deposits` permission. (Agents prohibited).
- Verification & Approval: Super Admin and Branch Admin.
- Tests: `tests/Feature/DepositLifecycleManagementTest.php`, `tests/Feature/SimplifiedDepositWorkflowTest.php`, `tests/Feature/FixedDepositAnnualCompoundInterestTest.php`, `tests/Feature/RdDepositCalculationTest.php`.

## 9. Installment Collections & Verification Module

Schedules, records, and reconciles periodic deposit installments (daily pigmy savings and monthly recurring contributions).

### Responsibilities
- Generate installment schedules with due dates and due amounts.
- Record counter or field collections with payment modes (Cash, UPI, Cheque, Bank Transfer).
- Support 2-step verification: Field collections remain `UNVERIFIED` until verified and reconciled by Branch Operations Staff.

## 10. Multi-Tier & Multi-Year Commission Engine Module

### Purpose
Automates the calculation, annual amortization, hierarchical override distribution, and multi-stage payment disbursement of agent commissions.

### Responsibilities
- Calculate direct booking commission and upline differential overrides:
  $$DifferentialRate = UplineRate - DownlineRate$$
- Amortize commissions annually across multi-year Fixed Deposit tenures (Year 1 to Year 7) using `payout_year`.
- Prevent duplicate commission generation via transaction locks (`lockForUpdate`).
- Decimal-safe precision using PHP `bcadd`.
- Enforce the 4-step financial voucher workflow:
  `PENDING` &rarr; `APPROVED` &rarr; `PAYABLE` &rarr; `PAID` (or `REJECTED`).
- Record payment mode, transaction voucher reference, and paying officer audit stamps.
- CLI synchronization command: `php artisan commission:sync-fd-schemes`.

### Important Files
- Controllers: `app/Http/Controllers/Admin/CommissionController.php`, `SuperAdmin\DepositCommissionSchemeController.php`
- Services: `app/Services/CommissionService.php`, `FdCommissionSchemeService.php`
- Models: `app/Models/Commission.php`, `DepositSchemeRankCommission.php`, `CommissionRule.php`
- Views: `resources/views/admin/commissions/`

### Permissions & Tests
- Commission Approval / Payment: Super Admin and Branch Admin.
- Agent: Read-only access to personal commission ledger (`/agent/dashboard`).
- Tests: `tests/Feature/CommissionEngineTest.php`, `tests/Feature/FdCommissionManagementTest.php`, `tests/Feature/MultiYearDepositCommissionTest.php`, `tests/Feature/SyncFdCommissionSchemesTest.php`.

## 11. Career Progression & Promotion Engine Module

### Purpose
Calculates real-time agent productivity metrics, tracks milestones across the 12 standardized career ranks, and automates the promotion application and approval process.

### Responsibilities
- 12 standardized levels: Level 1 `Facilitator` to Level 12 `Deputy Director`.
- Dynamic rule criteria configured per rank by Super Admin: active customers, personal deposit volume, collection turnover, tenure duration, and qualifying downline agent tiers.
- Calculate composite 100-point performance score (`CareerPerformanceService`).
- Provide agents with real-time milestone progress bars and self-service promotion request submission.
- Process administrative review, rank updates, and permanent recording in `career_histories`.

### Important Files
- Controllers: `app/Http/Controllers/SuperAdmin/PromotionRuleController.php`, `Admin\CareerController.php`, `Agent\PerformanceController.php`
- Services: `app/Services/PromotionEligibilityService.php`, `CareerPerformanceService.php`
- Models: `app/Models/PromotionRule.php`, `PromotionRequest.php`, `CareerLevel.php`, `CareerHistory.php`
- Views: `resources/views/superadmin/promotion-rules/`, `resources/views/admin/career/`, `resources/views/agent/performance/`

### Permissions & Tests
- Rule Configuration: Super Admin only.
- Promotion Approval: Super Admin and Branch Admin.
- Promotion Application: Field Agents.
- Tests: `tests/Feature/CareerAndPromotionManagementTest.php`.

## 12. Reports, Business Intelligence & Data Export Module

### Purpose
Aggregates operational metrics across branches and produces tabular reports with one-click streaming CSV exports.

### Responsibilities
- Generate high-level KPI summaries and tabular reports for:
  - Customers Report (Demographics, KYC status, branch distribution).
  - Deposits Portfolio Report (Active balances, maturity dates, scheme types).
  - Commissions Report (Pending vs. paid amounts, agent breakdown, payment modes).
  - Agent Performance Report (Top producers, team deposit volumes, downline count).
  - Career Progression Report (Promotions history, rank distributions).
  - Financial Audit Logs (Chronological event ledger).
- Stream clean CSV data exports with branch-scoped access controls.

### Important Files
- Controller: `app/Http/Controllers/Admin/ReportController.php`
- Service: `app/Services/ReportService.php`
- Views: `resources/views/admin/reports/`

### Permissions & Tests
- Access restricted to Super Admin and Branch Admin (Branch Admins are strictly scoped to their own branch).
- Agents and Staff are blocked by default.
- Tests: `tests/Feature/ReportsAndAnalyticsTest.php`.

## 13. Financial Audit Logging & System Settings Module

### Purpose
Guarantees institutional transparency and audit compliance by recording immutable event logs and centralizing system parameters.

### Responsibilities
- Automatically log sensitive events: deposit status changes, commission approvals and payments, career promotions, and permission updates.
- Store actor ID, IP address, branch ID, event name, transaction monetary amount, and full before/after JSON snapshots.
- Manage system settings: organization identity, contact email, sequential numbering prefixes, and operational parameters (`settings` table).

### Important Files
- Model: `app/Models/AuditLog.php`, `Setting.php`
- Service: `app/Services/NumberingService.php`
- Views: Included in audit views and administrative headers.

### Permissions & Tests
- Audit view: Super Admin and Branch Admin (scoped).
- Settings mutation: Super Admin only.
- Tests: `tests/Feature/SecurityAndAuditLoggingTest.php`, `tests/Feature/SecurityAndFinancialAuditRemediationTest.php`, `tests/Feature/SystemSettingsManagementTest.php`.
